# USA Trip 2026 — V11 Supabase + PWA

החבילה הזו שומרת את V10 מבחינת עיצוב/מסלול/מפה ומוסיפה:

- Supabase Auth
- סנכרון משותף בין מכשירים
- Supabase Realtime
- localStorage כ-cache מקומי לעבודה גם בלי חיבור
- תור סנכרון פשוט: שינוי נשמר מיד מקומית ונשלח לענן כשהאינטרנט זמין
- הגנת RLS במסד הנתונים
- PWA: manifest + service worker + icons
- גיבוי JSON ידני מתוך כפתור הענן

## מה מסתנכרן
ה-state הדינמי שכבר קיים באפליקציה:

- הוצאות
- הזמנות שהוספתם
- פעילויות שהוספתם
- מקומות שהוספתם
- הערות יומיות
- סימוני "בוצע"
- סימוני "ביקרתי כאן"
- עריכות אישיות של תחנות

המסלול, FOMO והמסעדות עצמם נשארים בקוד האפליקציה ונעדכנים באמצעות גרסאות HTML חדשות.

## שלב 1 — Supabase

1. צור Project חדש ב-Supabase, למשל `USA Trip 2026`.
2. פתח SQL Editor.
3. הדבק והריץ את כל `supabase_trip_schema.sql`.
4. עבור ל-Authentication > Users וצור משתמש משפחתי אחד עם Email + Password.
   - את אותו משתמש אפשר להכניס בכל הטלפונים המשפחתיים.
5. מצא את:
   - Project URL
   - Publishable Key
6. פתח `config.js` והחלף רק את שני ה-placeholders.

אין להכניס לקבצי האתר Secret Key או service_role.

## שלב 2 — GitHub Pages

1. צור Repository חדש, למשל `usa-trip-2026`.
2. העלה את **תוכן התיקייה**, כך ש-`index.html` יהיה בשורש ה-Repository.
3. Settings > Pages.
4. Deploy from a branch > `main` > `/ (root)`.
5. המתן לכתובת GitHub Pages.

## שלב 3 — בדיקת סנכרון

1. פתח את האתר במחשב/טלפון הראשון.
2. לחץ על כפתור הענן בפינה השמאלית העליונה.
3. התחבר עם החשבון המשפחתי.
4. במכשיר הראשון, אם בענן עדיין אין מידע, הנתונים המקומיים יעלו אוטומטית.
5. פתח את אותו URL במכשיר שני והתחבר עם אותו חשבון.
6. שנה משהו במכשיר א': למשל סמן "ביקרתי כאן" או הוסף הוצאה.
7. ודא שהשינוי מופיע במכשיר ב'.

## Offline

האפליקציה ממשיכה לכתוב מיד ל-localStorage. אם אין אינטרנט, השינוי נשמר מקומית. כשהחיבור חוזר, האפליקציה מנסה לסנכרן אותו.

אם בינתיים אותו state השתנה במכשיר אחר, האפליקציה **לא דורסת בשקט**: היא מציגה בחירה בין הגרסה המקומית לגרסת הענן.

## התקנה כ-PWA

לאחר פתיחת אתר GitHub Pages ב-Chrome באנדרואיד:

- תפריט ⋮
- Install app / Add to Home screen

האפליקציה תיפתח כאפליקציה עצמאית. המפה עצמה עדיין זקוקה לאינטרנט כדי לטעון אריחי מפה חדשים.

## עדכוני גרסה בהמשך

כשמעדכנים מסלול/מסעדות:

- מחליפים את קבצי האפליקציה ב-GitHub.
- לא מוחקים את טבלת `trip_state`.
- הנתונים המשפחתיים ממשיכים להישאר ב-Supabase.
